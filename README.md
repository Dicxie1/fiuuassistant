## Project Description

*Fiuu!** is a user-centered mobile application designed to help university students—particularly those studying Psychology—improve both their academic performance and emotional wellbeing.

The application combines two main components:
- 📚 Academic self-study tools
- 💚 Emotional regulation and wellbeing support
